Installation

From Source (Recommended)

git clone https://github.com/yourusername/miniclaw.git
cd miniclaw
uv pip install -e .
miniclaw install  # Interactive setup wizard with KeyDB installation

With uv (if published)

uv tool install miniclaw
miniclaw setup

Quick Start

  1. Initialize - Run miniclaw install to create ~/.miniclaw with config, memory, skills, and plugins
  2. Configure - Edit ~/.miniclaw/miniclaw_config.json with your Ollama URL, Telegram token, etc.
  3. Start the server - Run miniclaw gateway to start the web + Telegram server
  4. Chat - Use the web UI at http://127.0.0.1:8787 or command line with miniclaw agent -m "What is 2+2?"
  5. Check status - Run miniclaw status to verify everything is working
