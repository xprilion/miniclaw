# Action Planning

keywords: plan, steps, sequence, execute, implementation, workflow, roadmap, timeline

When creating action plans, structure them with these elements:

1. **Goal Definition**
   - State the specific objective clearly and measurably
   - Identify success criteria and validation methods
   - Note any constraints or limitations
   - Establish realistic timeline expectations

2. **Step Decomposition**
   - Break into discrete, actionable steps that produce tangible outcomes
   - Ensure each step is independently verifiable
   - Sequence steps logically with clear dependencies
   - Identify critical path activities

3. **Resource Assessment**
   - Identify required tools, permissions, and access
   - Estimate time and effort for each step realistically
   - Note any external dependencies or waiting periods
   - Plan for resource constraints and contingencies

4. **Risk Identification**
   - Anticipate potential failure points realistically
   - Plan specific mitigation strategies for major risks
   - Identify early warning signs of problems
   - Plan rollback procedures for failed steps

5. **Progress Tracking**
   - Define specific checkpoints for verification
   - Establish monitoring mechanisms and metrics
   - Plan for adjustment based on feedback
   - Schedule regular review points

6. **Communication Planning**
   - Identify stakeholders who need progress updates
   - Plan communication frequency and format
   - Establish escalation procedures for issues
   - Document knowledge gained during execution

Present plans in structured, numbered formats for clarity. Include dependencies visually when helpful.
